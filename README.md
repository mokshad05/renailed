# ReNailed: Forward Vision 2026

Static site for GitHub Pages. All files sit in the repo root (no folders).

- `deck.html`: the pitch deck (21 slides). Arrow keys or swipe, **N** notes, **F** full screen. Link a slide with `deck.html#<slide-id>`, e.g. `deck.html#appx`.
- `fin.html`: financial model, verified inputs only.
- `index.html`, `brief.html`, `bench-3d.html`, `3d.html`, `products-3d.html`: site pages.

Live at https://mokshad05.github.io/renailed/ (note the /renailed/ at the end).
