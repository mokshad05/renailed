# ReNailed: Forward Vision 2026

Static site for GitHub Pages.

- `deck/`: the pitch deck (21 slides). Arrow keys or swipe to move, **N** for speaker notes, **F** for full screen. Link to any slide with `deck/#<slide-id>`, e.g. `deck/#appx` for the appendix index.
- `index.html`, `brief.html`, `fin.html`, `bench-3d.html`, `3d.html`, `products-3d.html`: the existing site pages.

## Publish
1. Upload everything in this folder to the root of the `renailed` repo (Add file -> Upload files), commit.
2. Settings -> Pages -> Source: Deploy from a branch, `main`, `/ (root)`.
3. Deck URL: https://mokshad05.github.io/renailed/deck/
